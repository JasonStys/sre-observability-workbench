## File-type and responsive-layout boundaries

The native file-input path exposed an existing stat-before-open availability gap. Acquisition now uses nonblocking/no-follow flags and validates the actual opened regular descriptor before reading, while retaining byte caps and strict JSON contracts. A Windows test opens the actual harmless NUL device at the acquisition boundary and requires refusal plus descriptor closure. POSIX CI replaces a real regular file with a no-writer FIFO inside a bounded child; this test explicitly skips on Windows, not silently passes. This does not establish hostile shared-directory snapshot integrity or defend against an administrator.

Actual visual inspection also found long Infrastructure status text squeezing the Exit label. The native footer now sizes status wrapping to its remaining width, preserving every lifecycle button. Actual packaged acceptance resizes to 980×700, uses a long status and checks full button width/viewport bounds plus uncut status height before restoring the normal presentation size. Screenshots capture only each owned window through PrintWindow; no desktop fallback or fabricated UI is used.

## Diagnosed hosted startup failure

The initial macOS draft checks failed two actual threaded-controller tests; their fixed ten-second wait and cleanup assertions were retained. A follow-up diagnostic source added bounded thread/frame identities without local variables or evidence contents. [The actual failed job](https://github.com/JasonStys/sre-observability-workbench/actions/runs/42946830617/job/130281537262) showed both blocked workers at `socket.getfqdn` → `HTTPServer.server_bind` → the owned `Server` constructor, before request execution. This is a diagnosed unnecessary reverse lookup in the project startup path; it is not a finding about SDK resource detection or proof of an unrelated runner fault.

The owned service now overrides the documented [socketserver bind hook](https://docs.python.org/3.14/library/socketserver.html#socketserver.BaseServer.server_bind) with the actual TCP bind, fixed numeric loopback name and actual OS-assigned port. [CPython's HTTPServer implementation](https://github.com/python/cpython/blob/v3.14.10/Lib/http/server.py) otherwise performs reverse DNS after binding. An independent real threaded-service test forbids `getfqdn`, then requires both actual ephemeral services to start, respond and close normally. It fails the old constructor without waiting for a network resolver. No listener reuse, timeout increase, skipped platform, altered fault denominator or retry was introduced. Final hosted results remain separately bound to the corrected source.
